## Что нужно для пилота M365

Подготовка к пилоту 2026-10-17: исправлены расхождения Azure-конфигурации (nonce Key Vault, hostname и закрытый P2, forwarded headers, сохранение minimum version, smoke агента и после swap); добавлены проверка Production-bootstrap, правила оповещений P2, редактор Windows-политик, отзыв устройств по ключу, RB-13, ручной конвейер кандидата MSI. Состояние и порядок реальной приёмки — [dev/pilot-readiness.md](dev/pilot-readiness.md). Доступы владелец предоставит позже; Azure/tenant/Windows/RMM в этой работе не проверены. Гейты и пилоты остаются открытыми.

- Вход владельца в Azure и tenant компании в его терминале (`az login`) и подтверждение расходов (~110–125 USD в месяц), затем `infra/scripts/setup.sh prod` и `deploy-app.sh prod`.
- Для SP-01 — tenant компании и пробные tenant (Business Premium и Business Standard); tenant клиентов до договоров обработки данных не используются.
- Роли сотрудников в Enterprise application «Sikkerheit Portal», Conditional Access с MFA для портала, поток Workflows для сводки Teams.
- Инструменты установлены (2026-10-16): .NET 10 SDK, Node 24 LTS, Azure CLI с Bicep; Docker Desktop уже был.

Подробности — [dev/offline-improvements.md](dev/offline-improvements.md), [dev/atera-inventory.md](dev/atera-inventory.md).
