# Sikkerheit

Сервис регулярной проверки безопасности Windows и Microsoft 365 для клиентов IT-компании: Windows-агент собирает факты, внутренний портал показывает техникам отклонения и историю, раз в неделю формируется отчёт.

Состояние на 2026-10-13: кода приложения нет. В каталоге только Development Package v0.1.0 — требования, архитектура и предложенные контракты, подготовленные для независимой оценки GPT-6 Astra и Fable 5.1. Репозиторий git, ветка `main`; v0.1.0 отмечена тегом `package-v0.1.0`. Стадии, гейты и текущий статус — [docs/WORKFLOW.md](docs/WORKFLOW.md).

Перед работой прочитать [docs/AI_CONTEXT_MAP.md](docs/AI_CONTEXT_MAP.md): там типовые задачи сопоставлены с минимальным набором файлов.

## Состав корня

- `development-package/` — версионируемый пакет: документы `01`–`10`, `specs/`, `examples/`, `scripts/`.
- `sikkerheit-app-chat-transcript.md` — первоисточник идеи: переписка начальника с ChatGPT на нюнорске. Не редактировать.
- `sikkerheit-development-package-v0.1.0.zip` — архив пакета для рецензентов, результат сборки.
- `AGENTS.md` — правила для всех агентов, Codex и Claude Code читают его сами. `docs/` — навигация и отчёты (`docs/reports/`). В пакет и архив они не входят: сборка берёт только содержимое `development-package/`.
- Не создавать `CLAUDE.md`, `.claude/CLAUDE.md` или `CLAUDE.local.md` ни в проекте, ни в родительских каталогах — в том числе командой `/init`. Если такой файл есть, Claude Code перестаёт читать `AGENTS.md`, включая `~/AGENTS.md`; глобальный `~/.claude/CLAUDE.md` на это не влияет. Заметки только для Claude добавлять в этот файл.

## Сгенерированные файлы

Не править вручную — следующая сборка перезапишет изменения:

- `scripts/generate_contracts.py` создаёт `specs/*.json` и `examples/*.json`. Контракты меняются в генераторе.
- `scripts/build_package.py` проверяет пакет и перезаписывает `VALIDATION.md`, `REVIEW-BUNDLE.md`, `manifest.json`, `source/boss-chat.md` (копия переписки из корня) и ZIP в корне.

Сборка запускается из любого каталога:

```bash
python3 development-package/scripts/generate_contracts.py
python3 development-package/scripts/build_package.py
```

Ошибка проверки останавливает сборку на `assert`; успешная сборка печатает JSON-сводку.

## Правила изменения пакета

- v0.1.0 подготовлен для независимой оценки, и оба рецензента должны получить одинаковую версию. Не менять и не пересобирать пакет без явного указания пользователя: сборка перезаписывает ZIP и `manifest.json`.
- Изменения по итогам ревью идут в следующую версию (0.2.0) вместе с журналом принятых и отклонённых замечаний — см. `09`, раздел «Сопоставление ответов». Где менять номер версии и даты — в карте контекста.
- Поведение задают `01`, `03`, `04`, `05`; OpenAPI и схемы уточняют поля и ответы. Противоречие между файлами — дефект пакета. Переписка объясняет происхождение идеи, но не является спецификацией.
- Документы пишутся на русском; идентификаторы, поля, endpoints и permissions — как в контрактах. Переписку на нюнорске не переводить и не исправлять.
- В `build_package.py` зашиты количества: 16 проверок, FR-01…13, AT-01…17, 12 сообщений переписки и числа в тексте `VALIDATION.md`. При изменении состава обновить их вместе; список — в карте контекста.

## Проверка

- Встроенная проверка покрывает только используемое подмножество JSON Schema и не заменяет стандартные валидаторы. Полная проверка OpenAPI и JSON Schema запланирована в WP-01; `jsonschema` и `openapi-spec-validator` на машине не установлены (2026-10-12).
- Перед пересборкой оригинала можно собрать копию во временном каталоге (`development-package/` вместе с перепиской) и сравнить её с оригиналом через `diff -rq`. На 2026-10-12 пересборка воспроизводит файлы пакета побайтно. Содержимое ZIP тоже совпадает, но хэш архива меняется при каждой сборке: в него записывается время файлов.

## Экономия контекста

- Не читать целиком `development-package/REVIEW-BUNDLE.md` (~6 400 строк, повторяет весь пакет) и `development-package/specs/openapi.json` (~4 300 строк). Контракт компактнее читать в генераторе или выборкой через `jq`.
- Документы `01`–`10` короткие по числу строк, но строки длинные (6–14 КБ на файл). Читать нужный раздел по заголовку `##`.
- Для поиска использовать `rg`. Функция `grep` в шелле Claude — это ugrep: шаблоны вида `.{0,80}` рядом с кириллицей превышают его лимит сложности.
